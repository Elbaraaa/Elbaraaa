I build full-stack products end to end — data model, API contract, interface, deployment. Most of
my recent work is in health-surveillance tooling, academic planning systems, and putting language
models behind deterministic validation so their output can be trusted in production.

The constraint that shapes my architecture decisions most is accessibility: interfaces that hold up
for older adults, first-time reporters, and people on poor connections. Currently migrating a legacy
participatory health-surveillance frontend to Next.js and TypeScript, which is largely the work of
making undocumented routing, caching, and API boundaries explicit.

## Selected work

**[OneHealth](https://github.com/Elbaraaa/OneHealth)** · Next.js · TypeScript · Tailwind
A One Health reporting and risk-awareness platform. Users submit lightweight human, animal, or
environmental health reports and receive cautious rule-based risk signals. Anonymous reporting is
supported and profiles are optional — a deliberate privacy decision, not a default.

**[MajorLyte](https://github.com/Elbaraaa/MajorLyte)** · Next.js · Gemini · SQLite
Academic planning for University of Arizona students. Gemini parses a transcript, maps completed
coursework onto degree requirements, validates every prerequisite chain, and produces a
semester-by-semester plan with risk flags. Advisors upload a PDF catalog and have each course
extracted into the database.

**[HackAZ](https://github.com/Elbaraaa/HackAZ)** · TypeScript · Vite · Neon · Cloudflare
Hackathon build with a dedicated auth service and an Alexa skill, so a report can be filed by voice.

**[Portfolio](https://github.com/Elbaraaa/Portfolio)** · [elbaraa.me](https://elbaraa.me)
Personal site and project index.

Not public: **Graduational** — AI academic planning platform, where I serve as co-founder and CTO;
**iDetect** — participatory health surveillance, developed in a private organization repository;
and a small graphics library in C targeting the Linux framebuffer directly.
