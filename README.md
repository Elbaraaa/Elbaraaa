I build full-stack products and like owning the whole path: the data model, the API contract,
the interface, and whatever it takes to get it deployed. Most of my recent work has been
health-surveillance tooling, academic planning, and putting language models behind
deterministic validation so the output can actually be trusted.

I care a lot about interfaces that work for people who aren't comfortable with technology —
older adults, first-time reporters, anyone on a bad connection. That constraint has shaped more
of my architecture decisions than any framework preference.

Right now I'm migrating a legacy participatory-health-surveillance frontend to Next.js and
TypeScript, which mostly means untangling routing, caching, and API boundaries that were never
written down.

### Some things I've built

**[OneHealth](https://github.com/Elbaraaa/OneHealth)** — a One Health reporting and risk-awareness
MVP. People submit lightweight human, animal, or environmental health reports; the app returns
cautious rule-based risk awareness. Anonymous reporting is allowed and profiles are optional,
which was a deliberate privacy call. *Next.js, React, TypeScript, Tailwind.*

**[MajorLyte](https://github.com/Elbaraaa/MajorLyte)** — an academic planning tool for University
of Arizona students. Gemini reads a transcript, maps completed courses onto degree requirements,
walks the prerequisite chains, and produces a semester-by-semester plan with risk flags. Advisors
can upload a PDF catalog and have every course extracted into the database. *Next.js, Gemini,
SQLite.*

**[HackAZ](https://github.com/Elbaraaa/HackAZ)** — hackathon build with its own auth service and
an Alexa skill on the side, so a report can be filed by voice. *TypeScript, Vite, Neon, Cloudflare.*

**[Portfolio](https://github.com/Elbaraaa/Portfolio)** — the site behind [elbaraa.me](https://elbaraa.me).

A few projects aren't public: **Graduational** (the AI academic planning platform I co-founded and
work on as CTO), **iDetect** (participatory health surveillance, in a private organization repo),
and a small graphics library in C that draws straight to the Linux framebuffer — that one taught
me more about the layers under a UI than any framework has.
